# .minion-models.md example

Copy one baseline into a project root as `.minion-models.md`:

```bash
cp baselines/openai-codex/.minion-models.md .minion-models.md
# or
cp baselines/cursor/.minion-models.md .minion-models.md
```

Then edit the concrete model names for that project's provider.

The file should define:

- provider
- Frontier → Minion routing
- Escalation routing
- alias block: `frontier`, `fast`, `code`, `deep`, `critic`
